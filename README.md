# Space Invaders 🎮

A classic arcade-style Space Invaders game built using **Python** and **Pygame**.

## 🕹️ About the Project

This project recreates the classic Space Invaders experience, where the player controls a spaceship and fights against enemy objects.

## 🛠️ Technologies Used

- Python
- Pygame

## 📂 Project Files

- `main.py` – Main game implementation
- Image assets – Player, enemies, background and other game visuals
- Audio assets – Background music and sound effects

## ⚙️ Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/vedhanth-t/space-invaders-pygame.git
   ```

2. Navigate to the project folder:

   ```bash
   cd space-invaders-pygame
   ```

3. Install Pygame:

   ```bash
   pip install pygame
   ```

4. Run the game:

   ```bash
   python main.py
   ```

## 📚 Learning Reference

Developed as a learning project while following a Pygame tutorial. The implementation was used to practise Python programming and game development.
